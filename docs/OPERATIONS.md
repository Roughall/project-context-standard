# Operations

## Recommended session cycle
1. Bootstrap from repository context.
2. Verify current state and task prerequisites.
3. Execute one scoped task.
4. Test and capture evidence.
5. Update status and handoff.
6. Review changes before commit/push.

## Git hygiene
- Inspect `git status` and the diff before editing and before committing.
- Never discard unrecognized user changes.
- Commit only when authorized by the user or project workflow.
- Report exact commit/push results; do not infer success from an attempted command.
