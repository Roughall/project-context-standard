# End Session Prompt

Before ending the session:
1. Review the diff and identify unintended or unrelated changes.
2. Run relevant tests; capture commands and actual outcomes.
3. Update `PROJECT_STATUS.md`, `TEST_RESULTS.md`, `CHANGELOG.md`, and `HANDOFF.md` as appropriate.
4. Mark incomplete or untested items `IN_PROGRESS` or `VERIFICATION_REQUIRED`, not `PASS`.
5. Report files changed, verification, blockers, and the next concrete action.
6. Do not commit or push unless the user or project workflow authorizes it.
