# Continue Project Prompt

Continue the current project using repository context as the source of truth.

- Bootstrap using `prompts/bootstrap.md` and project `AGENTS.md`.
- Identify the highest-priority next action in `HANDOFF.md` and `PROJECT_STATUS.md`.
- Verify prerequisites and acceptance criteria before editing.
- Make the smallest coherent change that advances the task.
- Run relevant tests and record actual results.
- Update status, changelog, and handoff.
- Report what changed, evidence, remaining risks, and the next action.
- Do not modify unrelated files or claim unverified success.
