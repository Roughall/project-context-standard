# Agent Handoff Prompt

Prepare a handoff for another agent who will not have this conversation history.

Include:
1. Objective and current milestone.
2. Verified completed work and evidence.
3. Current branch/repository and relevant file paths.
4. Exact next action and acceptance criteria.
5. Known blockers, risks, dependencies, and required approvals.
6. Tests run and tests still required.
7. Important approved decisions and constraints.

Update `HANDOFF.md` and `PROJECT_STATUS.md`. Do not include secrets or vague instructions such as “continue from here.” Clearly label unknown or unverified facts.
